# Images des cartes

Mets ici une image par carte, nommée d'après sa valeur : `1.png`, `2.png`, ... `9.png`
(les cartes actuelles ont une valeur aléatoire entre 1 et 9).

Format recommandé : PNG, fond transparent si possible. L'image sera automatiquement
redimensionnée pour remplir la case.

Si une image est absente pour une valeur donnée, la carte s'affiche avec un rectangle
de couleur et le numéro, en attendant.
